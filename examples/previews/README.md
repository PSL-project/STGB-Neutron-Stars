# Preview gallery

These seven PNGs are preliminary quick-mode sample results with user-supplied EOS tables, typically using SLy4, beta_V=-10, alpha=30 km² and central energy-equivalent density 8.1e14 g/cm³ (with parameter variations as indicated in each plot). They demonstrate the default figure *format and scientific visual checks*, not a completed published benchmark replication.

`01` Effective curvature-induced mass and scalar profile.
`02` Mass-radius curves, black dashed GR.
`03` Absolute scalar charge / mass, GR zero dashed.
`04` Fixed-density scan over alpha.
`05` Six separate EOS panels sharing axes.
`06` Pressure and energy profiles with visible dashed GR overlay.
`07` Linear fundamental zero-mode threshold curve.

Use `python run.py` to regenerate with your own parameters and higher resolution.
